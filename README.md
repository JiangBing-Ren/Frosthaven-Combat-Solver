# Frosthaven Combat Solver（霜港迷城战斗求解器）

《霜港迷城》(Frosthaven) PC 数字版的**战斗推荐助手**：BepInEx 插件 + 离线测试台。

> **本仓库是私有的**：包含游戏 DLL 的反编译产物（`decompiled/`、`extracted/`），
> 用于规则查证。这些内容属于游戏厂商，仅供内部研究。

---

## 它做什么

在战斗中选择角色时按 <kbd>Insert</kbd>，弹出一个窗口，按回合给出**可执行的行动建议**：

- **当前回合**：出哪两张牌的哪半、站哪、���谁、伤害多少、会翻出哪张修正牌
- **后续回合**：第 2、3 回合的推演（沿第 1 回合的最佳方案继续），含敌人真实抽牌
- **敌人动向**：每个敌人的意图、落点、先攻
- **生存提示**：这个落点会不会挨打、会不会被打死、敌人会给你上什么状态

## 核心设计

| 方面 | 做法 |
|---|---|
| 修正牌 | **确定量**，不是随机变量（游戏抽牌直接取牌堆顶）→ 可精确预知，实测 354/354 全中 |
| 评估 | **词典序 Pareto**：会不会死 > 少挨打 > 击杀 > 有效伤害 > 治疗 > 线性分（学 StS2 Combat Solver） |
| 搜索 | 束搜索 + **多样性分桶**（Top-N 不全是同一路子的变体） |
| 生存维度 | 威胁按**方案先攻**分组 → 换一张先攻更高的牌就能避开敌人的先手 |
| 建模范围 | 射程/视线/移动/寻路/陷阱/冰面/危险地形/状态条件/阴影(死行)/AOE 多目标/治疗/强化/元素提示 |

## 目录

```
src/FHSolver/          插件源码（net472，Unity Mono）
src/FHSolver.Tests/    离线测试台（纯 C#，不需要游戏，237 项断言）
tools/                 构建与校验脚本
decompiled/            游戏 DLL 的反编译产物（规则查证用）
extracted/             游戏规则数据（Base.ruleset）解包结果
SOLVER_DESIGN.md       设计文档（每个特性的推理与踩坑记录）
```

## 构建

```bash
bash tools/build.sh
```

会依次跑：反射目标静态校验 → 编译插件 → 跑离线测试台 → 部署到游戏目录。

## 重要约定

- **改前先 `git status`**（本项目 2026-10-25 曾因脚本失误丢失过一个 1584 行的文件）
- 改源码用 `python3 tools/patch.py <文件>`（**原子写**，不会截断原文件）
- 新增反射调用后，**必须**在 `tools/verify_reflection.py` 的 `EXPECTED` 里登记
- 反馈里提到的"未建模清单"在插件的「报错」页，`SOLVER_DESIGN.md` 里有完整版
